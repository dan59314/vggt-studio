
左側中間工作區以四個分頁呈現：② 快速推估、③ 點雲調整、④ 高品質重建、⑤ 網格預覽。每頁独立捲動，切換保留參數及捲動位置，不會自動執行推估。上下固定區域及高度分隔線保留；匯出統一使用「檔案 → 輸出」。

主體選取（照片或影片抽幀）
- 在①輸入資料按「主體選取／遮罩…」。先拖曳框選主體，再按「框選後分割」。
- 「追蹤至後續影格」由目前影格向後產生遮罩；已有遮罩作為追蹤參考且不覆寫。若需重新追蹤某張，先清除該張遮罩。
- 綠色為保留區；可切換原圖／黑白遮罩，使用保留與排除筆刷修正，或匯入同比例黑白 PNG（白色保留）。
- 每張需按「確認本張」，全部確認後才能「套用全部遮罩」。編輯工作副本不會修改已套用遮罩；取消追蹤不提交部分结果。
- 主畫面勾選「只保留選取主體」後，在③套用點雲，或先進行②／④推估；⑤重建網格後由檔案選單輸出。
- 遮罩改動會使先前點雲與網格失效，必須重新套用。相機仍用完整影像估計；主體遮罩限制點雲、補洞和 Mesh 幾何。原始預測預覽、來源影像與深度圖保留完整內容。
- 遮罩設定隨程式關閉保存於 LocalAppData/VGGT Studio，依來源完整路徑匹配；缺少遮罩會提示，不能默認保留背景。
- 這是本機 OpenCV GrabCut 框選分割與 Farneback 光流追蹤，無需額外模型下載；不是文字辨識金門大橋的語意模型。快速航拍、跨大角度、遮擋、低對比海面與細鋼索需人工修正。遮罩編輯最長邊 1024，不能恢復 VGGT 未重建出的細節。
- OpenCV 官方參考：https://docs.opencv.org/4.x/d8/d83/tutorial_py_grabcut.html 、 https://docs.opencv.org/4.x/dc/d6b/group__video__track.html
- 驗證：Python 23 項測試；validation/SubjectSmoke 的介面框選、追蹤、筆刷、逐張確認與套用測試；integration.py 驗證六視角快取的遮罩點雲、貼圖 GLB 與 Viewer 專案輸出。

遮罩精修工具（MaskEditor 版本）
- 「＋新增遮罩／－消除遮罩」直接修改保留區；游標圓圈代表實際筆刷範圍。
- 「多邊形新增／多邊形消除」逐點建立輪廓，雙擊、Enter 或「完成多邊形」填入，Esc 取消尚未完成的輪廓。
- 滾輪以游標為中心縮放，最多16倍；中鍵拖曳或使用「平移」工具移動畫面。「重設縮放」回到全圖。
- 「復原／重做」支援 Ctrl+Z／Ctrl+Y，涵蓋筆刷、多邊形、匯入、清除及重新分割。限目前影格最近20步；切換影格會清除復原歷史，但已編輯遮罩及提示保留。
- 「遮罩不透明度 %」調整綠色覆蓋濃度，不改變輸出遮罩。
- 「保留提示」（青色）與「排除提示」（紅色）不直接修改遮罩。畫完按「依提示重新分割」，GrabCut 將提示作為必須保留／排除的條件；其他像素可重新分類。完成後提示清除，復原可一起找回原遮罩與提示。
- 若結果不佳，復原後增加提示再試；直接筆刷修改不會自動成為重新分割的硬性條件。
- 尚有未套用提示時不能確認本張或由本張追蹤；可重新分割或清除提示後繼續。
- 實際大橋影格測試位於 validation/SubjectSmoke/bridge-before-after.png（左為框選，右為加入提示後）。天空與山景誤選減少，但仍非完美主體遮罩，細鋼索及剩餘背景需人工精修；不會變更使用者已套用的遮罩。

自動找物件（AutomaticObjects 版本）
- 在「主體選取／遮罩」選擇代表影格，按「自動找物件…」，SAM ViT-B 自動產生最多120個候選區域，包含物件、局部結構與背景，不提供物件語意名稱。
- 本機處理，無影像上傳；首次下載官方模型約360 MB，存於 LocalAppData/VGGT Studio/models。使用 CUDA，沒有 CUDA 時使用 CPU。此工作區已安裝 segment-anything==1.0；其他 Python 環境請安裝 python/requirements-automatic-objects.txt，沿用既有 torch/torchvision。
- 候選視窗可查看所有候選、已勾選物件或原圖。點影像切換該位置最小的候選；重疊區域可從清單選擇。多選後按「合併選取並使用」，以聯集建立本張遮罩，並取代目前工作副本（可復原）。取消不變更原有遮罩。
- 同次遮罩編輯期間，重開相同影格的自動找物件會重用候選。每张影格獨立，沒有把其他影格的候選誤用到目前影格。
- 合併後可筆刷修正、逐張確認，再由目前影格追蹤後續影格。追蹤仍使用既有光流流程，非 SAM 影片追蹤；跨角度或細鋼索需檢查。
- 驗證：實際大橋影格 GPU 自動分割產生25個候選；validation/AutoObjectsSmoke 驗證影像點選、多選聯集、空選取拒絕與套用復原；既有遮罩工具測試通過。
- 官方模型／程式來源：https://github.com/facebookresearch/segment-anything ，checkpoint：https://dl.fbaipublicfiles.com/segment_anything/sam_vit_b_01ec64.pth 。

深度分布與範圍預覽（DepthPreview 版本）
- 完成②快速推估或④高品質推估後，在③按「深度分布與範圍預覽…」。舊有含 predictions.npz 的快取也可使用，不需重新執行 AI。
- 分布圖統計原始有效深度（若啟用主體遮罩則先限制於遮罩內），最多取樣40000點進行互動預覽。每點保留來源相機深度，不以點雲中心距離代替。
- 近／遠雙滑桿採 log(1+深度) 刻度，數字框可精確設定模型相對深度。滑桿以資料最大深度為範圍，上限100000；數字框沿用主介面的0～100000範圍。
- 範圍外點顯示灰色，可取消勾選以隱藏。顯示的保留／排除數量是取樣點數；調整時保留視角及固定場景尺度。
- 預覽不包含信心、平滑、連通區域與補洞的處理效果。按「帶回③深度參數」僅更新近／遠設定，再按③「套用並更新點雲」正式處理；⑤重建網格後才可輸出新的GLB。取消不改變原設定。
- 驗證：26項Python測試；validation/DepthPreviewSmoke 使用六視角快取驗證分布、40000點灰色／隱藏效果、視角保留及滑桿上下界。
